# Randint Test

It's a little program to test how many times we get the same number when using the function randint 

At the end we get some statistics to view that.

Exemple : 

```
❯ ./main.py --test 2 --start 0 --end 10
Valeur 0 : 2 fois, soit 10.0%
Valeur 2 : 3 fois, soit 15.0%
Valeur 3 : 3 fois, soit 15.0%
Valeur 4 : 1 fois, soit 5.0%
Valeur 5 : 1 fois, soit 5.0%
Valeur 6 : 3 fois, soit 15.0%
Valeur 7 : 1 fois, soit 5.0%
Valeur 8 : 3 fois, soit 15.0%
Valeur 9 : 1 fois, soit 5.0%
Valeur 10 : 2 fois, soit 10.0%
```
